Политика конфиденциальности

Этот документ описывает, какие данные собирает Telegram-бот и связанное с ним веб-приложение (далее — «сервис») при оформлении заказа, и как эти данные используются.

Какие данные собираются

  • Telegram ID пользователя (для связи заказа с вашим аккаунтом в Telegram);
  • имя и username в Telegram (если указаны в вашем профиле);
  • номер телефона, который вы указываете при оформлении заказа;
  • адрес доставки (только при выборе доставки);
  • состав и история заказов (товары, суммы, способ получения и оплаты).

Зачем это нужно

Данные используются исключительно для оформления и выполнения вашего заказа: связи с менеджером, доставки, расчёта стоимости и подтверждения оплаты. Телефон сохраняется, чтобы не запрашивать его повторно при следующих заказах.

Кому передаются данные

Данные не передаются третьим лицам, за исключением случаев, необходимых для выполнения заказа (например, менеджеру, который его обрабатывает). Оплата картой происходит по прямому банковскому переводу — сервис не получает и не хранит данные вашей карты.

Хранение и удаление

Данные хранятся в базе данных сервиса. Чтобы запросить удаление своих данных, напишите менеджеру — контакт указан в разделе «Частые вопросы» бота.

Контакты

По всем вопросам, связанным с обработкой данных, обращайтесь к менеджеру в Telegram.
